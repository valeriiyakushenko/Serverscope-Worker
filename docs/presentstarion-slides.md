Слайд 2. Актуальність проблеми
На слайд
Велика кількість ігрових серверів
Відсутність зручного аналізу активності
Недостатня кількість історичних даних
Складність вибору якісного сервера
Що казати

Існуючі сервіси переважно показують лише поточний стан серверів. Користувач не бачить історію активності, зміни популярності та довгострокову статистику. Саме тому виникла потреба створити інформаційно-аналітичну платформу.

Слайд 4. Мета та завдання проєкту
На слайд

Мета:

Створення вебплатформи для збору, аналізу та візуалізації статистики ігрових серверів.

Основні завдання:

автоматичний збір даних;
збереження історії активності;
побудова рейтингів;
пошук і фільтрація серверів;
відображення аналітики.

Слайд 7. Математична модель рейтингу

Окремий слайд.

На слайд

Три фактори:

Популярність сервера
Стабільність роботи
Історичний тренд

Схема:

50% → популярність

25% → стабільність

25% → тренд

Що казати

На відміну від багатьох аналогів, рейтинг формується не голосуванням користувачів, а на основі об'єктивних статистичних показників.

Це одна з головних відмінностей проєкту.
